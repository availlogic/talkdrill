# TalkDrill - Screen Specifications

## 1. Overview & Screen Inventory

本文档定义 TalkDrill 各核心界面的布局规范、组件行为、状态变迁与输入校验规则。系统包含以下五大核心界面（全站 UI 界面严格采用 100% 英文设计 English UI，专为沉浸式外语环境设计）：

1. **Screen 1: Library Overview (篇目库概览界面)**
2. **Screen 2: Corpus Studio (语料录入与翻译工作室)**
3. **Screen 3: Drill Workspace (跟读强化训练工作台 - 核心交互场景)**
4. **Screen 4: Print & Export Sheet (纸质打印与导出面板)**
5. **Screen 5: Settings & BYOK Hub (系统设置与服务配置中心)**

---

## 2. Screen 1: Library Overview (篇目库概览界面)

### 2.1 Overview
- **界面名称**：篇目库概览 (Library Overview)
- **主要目的**：集中展示用户已录入的所有外语篇目、练习频次（如 128 / 500）、目标语种与最后练习时间，提供篇目的组织与快速唤起。
- **用户目标**：快速选取今日需要强化的篇目，或新建/归档/清理旧篇目。

### 2.2 Layout & Hierarchy
- **顶部操作栏**：品牌 Logo、全局篇目搜索框、语种筛选 Chip、新建篇目按钮（“+ 新建篇目”）、系统设置入口图标。
- **主体内容区**：
  - **Desktop (>= 1024px)**：自适应网格卡片流（3 列或 4 列），每个卡片展示标题、目标外语标签、环形进度指示器、打卡数字及操作菜单。
  - **Tablet (768px - 1023px)**：双列网格卡片，支持左右手势滑动。
  - **Mobile (< 768px)**：单列信息卡片流，右下角常驻悬浮新建按钮（FAB，尺寸 56x56px）。
- **底部状态区**：展示本地篇目总数、已达成 300/500 遍的篇目成就统计、本地存储使用量指示。

### 2.3 Components & Behaviors

| 组件名称 | 交互行为 | 视觉与可用状态 | 可见性规则 |
|---|---|---|---|
| **ArticleCard (篇目卡片)** | 点击进入对应篇目的 Drill Workspace；右侧提供快速操作按钮组：编辑按钮（调出 Studio 编辑模式并保留打卡进度）、归档/恢复切换按钮（移至归档或移回进行中）、永久删除按钮（二次确认后级联清除语料、音频与记录） | 悬浮高亮、按压缩放（scale 0.98）；达成 500 遍展示金色成就外边框 | Active 标签页仅展示活跃篇目；Archived 标签页仅展示已归档篇目 |
| **SearchFilterBar (搜索筛选栏)** | 输入关键词实时过滤篇目标题与正文；点击语种 Tag 过滤特定外语 | 默认、聚焦（2px 强调外圈）、带清除文本按键 | 常驻顶部 |
| **CreateButton (新建按钮)** | 点击跳转进入 Screen 2: Corpus Studio | 强调色背景、悬浮微亮、按压微缩 | 常驻顶部或移动端右下角 FAB |
| **StorageQuotaBadge (存储指示器)** | 展示 IndexedDB 估算空间使用百分比 | 正常绿点、接近 80% 变橙黄色并可点击提示 | 常驻底部微标 |

### 2.4 Validation & Constraints
- 搜索框输入最大长度 100 字符，输入时防抖 150ms 过滤。
- 删除卡片时弹出二次危险确认模态框，提示“此操作将同时删除本地音频与所有打卡记录”。

### 2.5 Screen States
- **Loading State**：骨架屏卡片脉冲加载（通常 < 50ms）。
- **Empty State**：
  - **Active 视图为空**：展示 Sparkles 极简图标、"No Shadowing Drills Yet" 引导文案及 "+ Create First Drill" CTA 按键。
  - **Archived 视图为空**：展示 Archive 归档图标、"No Archived Drills" 说明文案（不展示创建按键，因新建篇目默认进入 Active 区域）。
- **Populated State**：卡片按最后练习时间（`lastPracticedAt`）降序整齐排列。
- **Offline State**：完全正常展示，右上角展示“离线就绪”图标。

### 2.6 Navigation
- **下一级**：点击卡片 -> 进入 Screen 3: Drill Workspace；点击卡片编辑按钮 -> 进入 Screen 2: Corpus Studio (Edit Mode)；点击新建 -> 进入 Screen 2: Corpus Studio (Create Mode)。

## 3. Screen 2: Corpus Studio (语料录入与翻译工作室)

### 3.1 Overview
- **界面名称**：语料录入与口语翻译工作室 (Corpus Studio)
- **主要目的**：引导用户导入/粘贴文本，选择翻译模式（需翻译 vs 自备外语），调用 AI 引擎生成本土母语级口语表达，绑定音频并持久化保存。
- **用户目标**：以最少步骤录入高质量外语料，并完成音频资产准备。

### 3.2 Layout & Hierarchy
- **Desktop (>= 1024px)**：左右分栏双编辑器布局。
  - 左栏：源文本录入区（支持拖拽 .txt 文件）、目标语种下拉框、高级口语 Prompt 展开配置面板、AI 翻译触发按钮。
  - 右栏：最终目标外语可编辑文本框、示范音频导入工作台（第三方生成音频/自有录音上传导入、文件就绪徽标、重新上传/移除）、保存并开始跟读主按钮。
- **Mobile (< 768px)**：分步式垂直流布局。
  - 第一步：输入源文本或直接输入外语。
  - 第二步：点击翻译生成外文（或直接润色）。
  - 第三步：上传/导入外部生成的示范音频（可选），底部吸底按钮“完成并开始跟读”。

### 3.3 Components & Behaviors

| 组件名称 | 交互行为 | 视觉与可用状态 | 可见性规则 |
|---|---|---|---|
| **SourceTextarea (原文录入框)** | 支持键盘输入、多行粘贴、直接拖拽 `.txt` 文件进入文本框区域 | 边框淡灰，输入文字字数统计实时变动 | AI 口语翻译模式下可见并支持输入；直接外语录入模式下隐藏 |
| **LanguageModeSwitch (模式切换)** | Tab 切换：“AI Spoken Translation (默认选中)”与“Direct Foreign Text” | 栅格双 Tab 切换器，选中项带蓝色边框与背景高亮，左侧为 AI 口语翻译，右侧为直接外语录入 | 常驻顶部核心位置 |
| **TargetLangDropdown (目标语种下拉)** | 选择目标外语（如 Castilian Spanish, Japanese, French, German 等） | 展开自适应列表，支持键盘首字母检索 | 仅在模式 A 下可见 |
| **TranslateActionButton (翻译触发按钮)** | 点击发起 LLM 口语翻译流式请求 | 正常状态为 Primary 强调按钮；请求中展示流式 Spinner 并置灰禁用；未配置 Key 时提示图标 | 仅在模式 A 下可见 |
| **TargetTextarea (目标译文编辑框)** | 翻译结果自动填充，支持光标选中文本自由编辑改写 | 多行自适应高度，行高 1.8，字号 18px，清晰可读 | 始终可见 |
| **AudioSection (示范音频导入区)** | 提供上传参考音频按钮（支持 .mp3 / .wav / .m4a <= 50MB）、第三方平台生成音频引导提示、就绪状态展示与替换/移除操作；编辑模式下自动加载已有音频并支持随时替换或彻底移除 | 包含引导提示卡片与文件选择控件；就绪后展示绿色就绪徽章与文件大小 | 始终可见，音频为可选配置 |
| **SaveStudioButton (保存主按钮)** | 新建模式下显示 "Save and Start Drill"；编辑模式下显示 "Save Changes"。点击更新 IndexedDB 并跳转至跟读空间，编辑模式下绝对保留原有打卡次数（currentCount）与日志历史 | 底部常驻，大尺寸高度 48px，Primary 强调色 | 始终处于视口显眼位置 |

### 3.4 Validation Rules
- **文本限制**：源文本与目标文本最大限制 20,000 字符；导入 `.txt` 文件必须 `<= 2MB`。
- **音频限制**：本地上传文件格式限定为 `.mp3`, `.wav`, `.m4a`，单文件 `<= 50MB`。
- **必填项约束**：目标外语文本（`targetText`）不得为空白字符串；若未绑定音频，保存时允许以纯文本朗读模式开启练习。
- **编辑一致性**：编辑已有篇目时更新标题、原文、译文与音频，不重置已累积练习次数。

### 3.5 Screen States
- **Translating State**：翻译中目标文本框呈现流式字打出动效，按钮显示“口语化重塑中...”。
- **Synthesizing Audio State**：音频生成中展示音频波形占位动效与进度提示。
- **Error State**：若 API 凭证错误或网络断开，在文本框上方弹出浅红告警条，附带“检查 API 设置”跳转链接与重试按钮。

### 3.6 Navigation
- **取消/后退**：点击左上角“< 返回”，若有未保存文本弹出“放弃当前草稿？”提示；
- **完成前往**：点击保存 -> 顺利进入 Screen 3: Drill Workspace。

## 4. Screen 3: Drill Workspace (跟读强化训练工作台 - 核心场景)

### 4.1 Overview
- **界面名称**：跟读强化训练工作台 (Drill Workspace)
- **主要目的**：本产品的灵魂界面。提供完全无干扰的沉浸朗读视口、专业音频播放控制（变调不变速、A-B 循环）以及极致低延迟的击穿式打卡与“正”字网格渲染。
- **用户目标**：心无旁骛，听一句读一句，按空格或轻触大按钮，一口气完成 300 至 500 遍过度学习突破。

### 4.2 Layout & Hierarchy
- **Desktop (>= 1024px) 三栏布局**：
  - **左侧导航收纳栏 (260px)**：当前篇目信息、上一篇/下一篇快速切换、返回篇目库。
  - **中央朗读主体区 (自适应 600px - 800px)**：
    - 顶部工具条：返回语料库、编辑入口（Edit Drill）、归档与恢复切换（Archive / Restore）、禅模式开关（Zen Mode，隐藏一切侧栏）、打印/导出入口、手动调整遍数（Adjust Repetition Count）。
    - 核心文本展示：大字号（22px - 26px），宽行高 1.8，字句清晰居中排版。
    - 底部吸底播放控制台：波形进度条、A-B 循环微调手柄、倍速切换药丸组（0.5x, 0.75x, 1.0x, 1.25x, 1.5x）、微步快退 2s / 快进 2s。
  - **右侧打卡与激励看板 (320px)**：
    - 大号阿拉伯数字实时进度（如 `342 / 500`），点击可直接编辑修改。
    - 撤销小按钮（快捷键 `Z` 提示）。
    - 完整的中国传统“正”字阵列网格（每 5 遍绘制一个完整正字，逐笔动态平滑勾画）。
    - 四大心理里程碑刻度轴与成就点亮状态。
- **Tablet (768px - 1023px) 双栏/折叠**：
  - 左侧支持手势抽屉收起；右侧打卡看板悬浮或合并至主朗读区下方。
- **Mobile (< 768px) 单栏拇指极致闭环**：
  - 核心文本占据全屏 70% 视口，字号 20px，行高 1.8。
  - 顶部紧凑标题与打印快捷入口。
  - 中下部：精简吸底 Mini 播放器（播放/暂停、倍速、A-B 开关），点击波形可向上滑动展开全功能调节面板。
  - **底部绝对常驻：超大尺寸打卡胶囊按钮**：
    - 按钮高度固定为 `58px`，横跨屏幕宽度（留左右 16px 边距），文案：“+1 朗读完毕 (342/500)”。
    - 胶囊左侧附带撤销图标按钮（`-1`）。
    - 单手握持时，拇指可完全实现盲操按压，无需注视按钮位置。

### 4.3 Components & Behaviors

| 组件名称 | 交互行为 | 视觉与可用状态 | 可见性规则 |
|---|---|---|---|
| **DrillTextDisplay (核心朗读文本)** | 用户朗读主体；支持选中个别短语开启局部循环 | 大字号、高对比度排版，支持在设置中切换深色高对比模式 | 常驻视口中心 |
| **AudioPlayerBar (专业播放控制台)** | 支持 Space 以外的快捷键：`R` 重播，`[` 减速，`]` 加速；拖拽手柄设定 A-B 断点 | 播放/暂停状态无缝切换；变速保持不变调；A-B 激活时区间高亮显现 | 绑定音频时完整展示；无音频时收缩为“静音跟读模式” |
| **BigDrillButton (大胶囊打卡键)** | 移动端拇指按压打卡，按压时带有弹性物理微缩放反馈（active: scale 0.96） | 高度 58px，Primary 强调高亮色，圆角全包（rounded-full） | 移动端常驻底部；桌面端可用鼠标点击或按 Space 盲打 |
| **ZhengMatrixGrid (正字阵列网格)** | 实时渲染 1 至 500 遍对应的正字方阵。每 5 次打卡完成一个标准 5 笔“正”字 | 灰白网格底色，已完成笔画采用深色实线平滑矢量渲染 | 桌面/平板右侧面板常驻；移动端支持下拉展示 |
| **MilestoneIndicator (里程碑刻度轴)** | 标注 50、150、300、500 刻度；达成时触发庆祝发光效果 | 达成点展示高亮勾选徽标，未达成为灰色圆圈 | 常驻看板中 |
| **NumericOverrideModal (数字直接修正弹窗)** | 点击计数字符唤出；用户可输入任意正整数覆盖当前进度 | 居中模态框，带原生数字软键盘，带确定与取消 | 点击数字后可见 |

### 4.4 Global Keyboard Shortcuts (Desktop 专属盲操)
- `Space`：打卡完成 +1（无视焦点，只要不在输入框内即生效）。
- `Z`：立即撤销上一次打卡 -1（最低至 0）。
- `R`：重新从头（或从 A-B 起始点）播放当前音频。
- `[` / `]`：降低 / 提高播放倍速（在 0.5x, 0.75x, 1.0x, 1.25x, 1.5x 之间循环）。
- `A` / `B`：播放中实时标记 A 点与 B 点。
- `Esc`：清除 A-B 循环标记。

### 4.5 Screen States
- **Normal Practice State**：音频循环流转，用户流畅打卡，正字网格无卡顿更新。
- **Milestone Pop State**：刚刚完成第 50 / 150 / 300 / 500 遍瞬间，屏幕中央浮现轻量徽标动效（耗时 1.2s，不阻断下一次按键）。
- **Zen Mode (禅模式)**：隐去左侧篇目栏、右侧正字面板与所有顶栏，仅保留核心外语音符与播放进度条，最大化降低心智干扰。

### 4.6 Navigation
- **打印面板**：点击顶部打印图标 -> 弹出 Screen 4: Print & Export Sheet；
- **编辑篇目**：点击编辑图标 -> 返回 Screen 2 调整译文或替换音频；
- **退出返回**：点击左上角库图标 -> 返回 Screen 1: Library Overview。

## 5. Screen 4: Print & Export Sheet (纸质打印与导出面板)

### 5.1 Overview
- **界面名称**：纸质打印排版与多端导出面板 (Print & Export Sheet)
- **主要目的**：将数字语料转换为便于物理书写与离线脱网朗读的高品质介质，支持直连打印机、导出标准 Markdown 及无损复制富文本。
- **用户目标**：将训练语料带到远离屏幕的书房、阳台或通勤路途中，手持铅笔勾划 300 至 500 遍“正”字打卡。

### 5.2 Layout & Hierarchy
- 采用居中抽屉或弹出卡片。
- **配置选项区**：
  - 打卡方格规模选择：单选按钮组（“60 个方格 - 对应 300 遍肌肉定型” vs “100 个方格 - 对应 500 遍脱口而出”）。
  - 排版预览微缩视图：展示大字号正文与页末整齐正方形打卡网格。
- **操作导出区**：
  - “发起纸质打印 (Print)”：强调色主按钮。
  - “导出 Markdown 文件 (.md)”：次级按钮。
  - “复制富文本表格 (Copy Rich Text)”：带图标次级按钮。

### 5.3 Print Media Query (`@media print`) 规范
- **元素隐藏**：自动隐去所有 Web 导航头、侧边栏、播放控件、按钮、遮罩层。
- **排版规格**：
  - 正文字号：固定为 `18pt`，正文字体为衬线或高质量人文无衬线体。
  - 文本行高：固定为宽松的 `2.2`，在行间留足铅笔手写国际音标（IPA）与连读弧线的空隙。
  - 页面下边缘：自动渲染整齐的正方形方格网格（60 格或 100 格），每格预留 20mm x 20mm 空间供用户手绘五笔“正”字。
  - 打印断页保护：关键段落与打卡网格应用 `break-inside: avoid`，严禁网格跨页切半。

### 5.4 Navigation
- 点击关闭按钮或背景遮罩 -> 返回 Screen 3: Drill Workspace。

## 6. Screen 5: Settings & BYOK Hub (系统设置中心)

### 6.1 Overview
- **界面名称**：系统设置与解耦配置中心 (Settings & BYOK Hub)
- **主要目的**：管理用户自备的翻译与 TTS 服务凭据，配置打卡声音偏好，执行本地数据备份与彻底抹除。
- **用户目标**：自主把控 API 成本与模型选择，确保隐私完全受控。

### 6.2 Layout & Hierarchy
- 垂直 Tab 分组或卡片分组：
  1. **外观与主题偏好 (Appearance & Theme)**：主题单选按钮组（System Default / Light Mode / Dark Mode），通过 class 类名机制联动全局画布与前景对比度，确保全站达成 WCAG AAA 级高对比可读性。
  2. **场景翻译配置 (Translation Engine)**：严格按照如下顺序提供三大核心配置项与同源代理选项：
     - **Anthropic-compatible Base URL**：端点地址输入框（默认 `https://api.anthropic.com/v1`，支持自定义兼容端点或同源 `/api/proxy/anthropic`）。
     - **Model Name**：模型名称输入框（默认 `claude-3-5-sonnet-20241022`）。
     - **API Key**：凭据密钥密码输入框（占位符 `sk-ant-...`，掩码保护）。
     - **同源代理开关 (Route through Cloudflare Same-Origin Proxy)**：勾选后请求走同源 `/api/proxy/anthropic` 边缘服务，彻底规避第三方服务引起的浏览器 CORS 预检阻断问题（对齐 relocate_wise 方案）。
  3. **语音合成配置 (TTS Engine - 规划中)**：内置在线 TTS 配置面板规划于下次大版本升级时提供；当前版本界面默认关闭该表单以保证产品聚焦于核心跟读打卡流。
  4. **数据存储与危险区 (Data & Danger Zone)**：持久化存储申请状态、存储占用百分比、导出整库 JSON 备份按钮、红色警告框“清空全部本地数据”。

### 6.3 Validation & Security
- API Key 输入框采用 `type="password"`，带“显示/隐藏”小眼睛切换图标。
- 点击“清空全部本地数据”弹出二次确认输入框，要求用户键入“DELETE”以防手滑。

### 6.4 Navigation
- 点击右上角“完成/关闭” -> 返回触发设置前的对应屏幕，新配置在前端即刻生效。
