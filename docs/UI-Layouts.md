# TalkDrill - UI Layouts & Wireframes Specification

## 1. Overview & Layout Strategy

本文档提供 TalkDrill 各核心界面的结构布局、区域层级划分与跨端线框图（Wireframes）。系统贯彻**移动端单手极速盲操**与**桌面端大屏三栏沉浸**的双重交互体验，并专门定义纸质排版打印（`@media print`）的物理实体版面结构。系统用户界面交互文案全面采用 100% 英文设计（English UI），以确保与外语练习场景深度契合。

---

## 2. Screen 1: Library Overview Layout (篇目库概览)

### 2.1 区域划分 (Layout Regions)
- **TopNav**：品牌标识、搜索框、语种筛选 Tag、操作区（新建按钮、设置图标）。
- **MainContent**：自适应多列卡片网格流。
- **BottomBar**：篇目总数统计、过度学习达成成就徽章、磁盘空间指示器。

-----------------------------------------------------------------------------------
