# TalkDrill - Project Vision

## 1. Project Vision (项目愿景)

TalkDrill 是一款面向追求地道“听”与“说”能力的外语学习者的高强度跟读强化 Web 工具。

产品基于二语习得理论（Second Language Acquisition）中的影子跟读法（Shadowing）与过度学习（Overlearning）机制，通过“精选语料 -> 地道口语翻译 -> 母语级音频磨耳 -> 300至500遍高频肌肉记忆朗读”的闭环，帮助学习者建立直接的声音与口腔发音肌肉神经通路，消除中介语翻译思维，实现外语脱口而出。

## 2. Target Users (目标用户)

- **进阶外语学习者**：具备良好英语基础或以英语为母语，正在强化学习第二/第三外语（如卡斯蒂利亚西班牙语、日语等）的学习者。
- **发音与口语突破者**：追求母语级口语语调、连贯节奏与听觉-肌肉记忆联结，希望突破“能看懂但无法流利说出”瓶颈的高强度练习者。
- **极简与自主学习者**：偏好极低认知摩擦、反感繁琐语法打卡，注重隐私保护并习惯自带模型凭据（BYOK）的自主学习者。
- **多场景练习者**：既需要在桌面端高频快捷打卡，又习惯利用碎片时间在移动端练习，或使用纸质打印件进行沉浸式大声朗读的学习者。

## 3. User Problems (用户痛点)

- **中介语翻译延迟**：传统外语学习者在大脑中经历“目标语言 -> 翻译中介语 -> 语法重组 -> 口腔发声”的繁琐转换，无法在真实交流中实现本能般的即时表达。
- **认知负荷过重**：现有主流语言学习软件充斥复杂的语法解析、繁琐的音标符号与琐碎的选择题，分散了注意力，阻碍了纯粹的声音输入与口腔肌肉物理复诵。
- **练习深度不足**：缺乏针对难点发音的精细单曲循环（A-B 循环）与 300 至 500 遍过度学习机制，无法帮助学习者跨越音素熟悉度到肌肉定型的门槛。
- **数字与纸质场景割裂**：数字化工具排斥实体纸质朗读体验，而传统纸质材料又缺乏高质量音频伴随与量化打卡工具，难以满足多样化的朗读习惯。
- **隐私侵犯与平台锁定**：传统应用强制绑定中心化账户与云端订阅，用户的私有语料、练习记录和生成资产被锁定在特定平台，存在数据丢失与隐私泄露隐患。

## 4. Product Goals (产品目标)

- **建立直接神经回路**：通过高频声音输入与纯粹口腔肌肉复诵，帮助用户跳过中介语心译过程，直接建立声音到发音肌肉的直觉映射。
- **构建零认知负担体验**：界面专注于语料呈现、音频跟读与打卡计数，去除一切不必要的语法讲解与冗余视觉噪音。
- **贯通双轨练习生态**：完美融合屏幕端极低摩擦打卡练习与纸质实体排版打印，满足不同环境与心境下的朗读需求。
- **坚持去中心化与隐私优先**：无需集中式用户注册，语料、音频及打卡数据完全保存在用户本地，所有第三方生成能力解耦由用户自持配置。
- **实现全平台无缝适配**：一套设计与交互逻辑覆盖桌面键鼠大屏、平板支架触控及手机单手盲操。

## 5. Core Capabilities (核心功能特性)

- **多模式语料录入与篇目管理**：
  - 支持多行纯文本直接粘贴与文本文件导入。
  - 支持智能判定语言模式：对于需要翻译的原文触发场景化口语翻译，对于目标语言文本直通音频准备。
  - 提供本地文章库管理，直观展示练习篇目、目标语言、练习进度（如 128 / 500 遍）与最后练习时间，支持篇目新建、重命名、归档与删除。
- **场景化地道口语翻译**：
  - 采用契合目标语言母语者日常口吻的翻译策略，输出自然地道的口语表达（如卡斯蒂利亚西班牙语本土人称与措辞习惯）。
  - 支持用户微调口语化提示词指令，并在生成后保留文本框人工微调能力。
- **音频获取与多源管理**：
  - 支持在线语音合成（TTS）一键拉取母语级示范音频。
  - 支持用户上传自有音频文件，兼容主流音频格式。
  - 提供音频本地持久化存储与离线播放能力，并支持已生成音频文件的本地导出下载，避免重复生成开销。
- **专业级跟读播放器与极低阻力打卡**：
  - 专业播放控制：支持微步快进快退、精细化无级/档位变速（变调不变速），以及精准 A-B 段落循环高频突破生僻发音难点。
  - 极低阻力打卡交互：桌面端支持键盘空格键（Space）盲操打卡，移动端与平板端提供大面积触控热区与底部常驻大尺寸打卡按钮。
  - 防误触与纠错：支持一键撤销（快捷键 Z）以及点击计数值直接输入修正完成次数。
  - 正向反馈与阶段里程碑激励：提供拟真机械音效反馈；支持阿拉伯数字统计与传统“正”字网格可视化；内置 50 遍（初识音素）、150 遍（意群连贯）、300 遍（肌肉定型）、500 遍（自动化脱口而出）心理里程碑提示。
- **纸质排版打印与外部导出**：
  - 专用纸质朗读排版：一键呼出系统打印，自动隐藏所有交互组件与播放控件，调整为大号字与宽松行高，留足纸质手写笔记空间。
  - 自动生成“正”字打卡表：在打印件末尾自动排版空白方格表（可自主选择 60 或 100 个方格，对应 300 或 500 遍手写划线记录）。
  - 多格式外部导出：支持导出带打卡表格的标准 Markdown 文件及富文本格式，便于迁移与排版分享。
- **解耦式自持服务配置**：
  - 翻译服务与音频合成服务完全解耦独立配置，由用户自主配置服务地址、认证密钥与模型参数。

## 6. Success Metrics (成功指标)

- **练习深度达成率**：单篇语料达到 300 遍（肌肉定型）及 500 遍（脱口而出）里程碑的篇目占比。
- **打卡交互流畅度**：打卡触发到界面视觉更新的延迟保持在极低水准，实现无感知瞬时响应。
- **双轨练习模式采纳率**：用户在屏幕端练习与纸质排版打印/导出之间的协同使用活跃度。
- **离线练习可用度**：脱离网络环境下本地文章库与音频的加载成功率与练习顺畅度。

## 7. Business Model (商业模式)

- **BYOK (Bring Your Own Key) 模式**：作为纯客户端离线优先工具发布，不设中心化服务订阅与强制收费门槛。
- **零平台基础设施开销**：通过去中心化架构使用户自主承担第三方模型与语音 API 消耗，消除集中式服务器运营负担。

## 8. Out-of-Scope (当前范围外)

- **中心化用户体系与社交功能**：不建立云端账号数据库，不提供跨用户排行榜、社交分享广场或社区论坛。
- **AI 自动发音打分与语音识别纠错 (ASR)**：坚持影子跟读法的核心理论，不引入机器打分算法造成的认知干扰与焦虑，发音校准完全依赖用户的自我听觉对比与过度练习。
- **复杂语法解析与词汇卡片系统**：不构建语法树分析、词根词缀拆解或间隔重复（SRS）记忆卡牌系统，保持纯粹的听读与肌肉复诵定位。
- **多设备端对端实时同步**：初期不实现跨浏览器或跨设备的自动化端到端后台数据同步。

## 9. Future Direction (未来展望)

- **本地录音即时回放对比**：在本地浏览器环境内录制用户发音并与示范音频波形同步比对，全程在本地内存完成，不上传云端。
- **用户自选去中心化同步**：支持用户挂载个人私有存储（如 WebDAV、个人云盘或本地文件系统同步）进行篇目数据与打卡进度的跨端备份。
- **多语种口语提示词预置库**：扩展支持更多小语种本土口语 Prompt 模板库，并支持社区提示词的导入与导出。
